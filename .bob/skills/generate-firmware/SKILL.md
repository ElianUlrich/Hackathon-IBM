# Generate Firmware

Follow these steps to turn a `project.json` into a complete, building PlatformIO firmware project.

## Step 1 — Read all inputs

1. Read the target `project.json` in full.
2. For every component in `components`, read `catalog/components/<catalog_id>.json`.
3. Note each component's `libraries` array — this drives `lib_deps`. Empty arrays mean no library needed.
4. Read `catalog/esp32_devkit_pins.json` to verify all GPIO assignments.
5. Identify the firmware target directory: `examples/<demo_name>/firmware/`.

## Step 2 — Build the file manifest

List every file to create before writing any of them:

```
examples/<demo>/firmware/
├── platformio.ini
├── include/
│   ├── pinmap.h
│   └── secrets.example.h          (only if app.wifi == true)
└── src/
    ├── main.cpp
    ├── lv_conf.h                   (only if screen driver is ili9341 or st7789)
    └── components/
        ├── <instance_id_1>.h
        ├── <instance_id_1>.cpp
        ├── <instance_id_2>.h
        ├── <instance_id_2>.cpp
        ...
        ├── display.h               (only if screen block is present)
        └── display.cpp
```

## Step 3 — Build lib_deps

Collect every entry from every catalog component's `libraries` array:
- Skip components where `libraries` is `[]` (relay, soil sensor — no library needed).
- Format each entry as: `<platformio_id>@<version>`
- DS18B20 produces two entries: OneWire and DallasTemperature.
- If a display is present: add TFT_eSPI (TFT) or U8g2 (OLED) from its catalog entry.
- If LVGL is needed: add `lvgl/lvgl@^9.x.x` (confirm version from catalog ili9341 entry).

## Step 4 — Spawn two parallel subagents

Spawn both subagents at the same time:

**Subagent A — sensor/actuator drivers**
Instruct it to generate `src/components/<instance_id>.h` and `src/components/<instance_id>.cpp`
for every non-display component (sensors and actuators only). Rules:
- Each class has `begin()` (returns bool, checks device presence) and `update()` (non-blocking).
- All pin constants and I2C addresses come from `pinmap.h` — no magic numbers.
- Use `millis()` for timing; respect `min_read_interval_ms` from the catalog.
- Serial error logging in `begin()` if device not found.
- File header comment: generated by PinPilot, source project.json, purpose.

**Subagent B — display/GUI code**
Instruct it to generate `src/components/display.h` and `src/components/display.cpp`
by activating the `lvgl-screen` skill. Pass the full `screen` block and the display
component's catalog entry.

## Step 5 — Wait and review subagent output

Wait for both subagents to complete. Review:
- Subagent A: confirm every non-display component has both `.h` and `.cpp` files.
- Subagent B: confirm display driver files were produced; check for v8 API symbols
  (`lv_disp_drv_t`, `lv_disp_draw_buf_t`) — if found, fix before proceeding.

Write all subagent-produced files to disk.

## Step 6 — Assemble firmware-dev-owned files

Write these three files yourself (do not delegate):

### `include/pinmap.h`
One `#define` per GPIO assignment and I2C address, derived from `project.json`:
- Component pins: read from `pin_mapping` (keyed by pin name) + bus assignments.
- I2C addresses: from component `i2c_address` field (or catalog default if absent).
- SPI frequency: from `buses.spi0.frequency`.
- I2C frequency: from `buses.i2c0.frequency`.
- Name format: `PIN_<INSTANCE_ID_UPPER>_<PIN_NAME_UPPER>` for component pins,
  `ADDR_<INSTANCE_ID_UPPER>` for I2C addresses.

### `src/main.cpp`
- `#include "pinmap.h"` and all component headers.
- `setup()`: `Serial.begin(115200)`, `Wire.begin(SDA_PIN, SCL_PIN)` once,
  then `<instance>.begin()` for every component, startup summary to Serial.
- `loop()`: `<instance>.update()` for every component, `lv_timer_handler()` every ~5 ms
  if a TFT display is present.
- No `delay()`. No magic numbers.

### `platformio.ini`
```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
lib_deps =
    <entry from lib_deps list>
    ...
build_flags =
    -D USER_SETUP_LOADED       ; (only if TFT display present)
    -D ILI9341_DRIVER          ; (or ST7789_DRIVER)
    -D TFT_MOSI=<pin>
    -D TFT_SCLK=<pin>
    -D TFT_CS=<pin>
    -D TFT_DC=<pin>
    -D TFT_RST=<pin>
    -D SPI_FREQUENCY=40000000
    -D LV_CONF_INCLUDE_SIMPLE  ; (only if LVGL is used)
    -I include
```
(Omit TFT/LVGL flags if no TFT display is in the project.)

If `app.wifi == true`, add `include/secrets.example.h` with placeholder SSIDs.

## Step 7 — Run the build

```
python scripts/build.py examples/<demo>/firmware
```

- **BUILD PASSED**: report RAM usage and flash usage from the build output. Declare success.
- **BUILD FAILED**: state "Switching to build-fixer mode (attempt 2 of 3)" and use the
  `mode` tool to switch to `build-fixer`.
